## [Released]

### v0.0.1 - "Starting Point" (Oct 27, 2025)

**Status:** Internal prototype, no public build

This marks the starting point of public development documentation.

#### What Exists
- Basic drift movement mechanics
- Player shooting system
- Bomb attack functionality
- 2 small test maps
- Basic enemy AI
- Programmer art (placeholder visuals)

#### What's Missing
- No progression system
- No complete game loop
- Limited content
- No audio/music
- No polish

#### Documentation
- Created public documentation repository
- Set up player-first structure
- Wrote roadmap through v1.0
- Defined v0.1 scope

**This is the baseline. Watch it evolve!**
