# v0.1.0 - "The Prototype"

**Target Release:** May 1, 2026
**Status:** In Planning (0% complete)

---

## 🎯 Goal

Create the first complete playable experience: 30-45 minutes of gameplay with clear beginning, middle, and end.

**Success Criteria:**

- A player can start, play through, and finish a complete run
- Core gameplay loop is fun and compelling
- Basic progression system works
- Technical foundation is solid for future versions

---

## ✅ What's Included

### Core Gameplay

- **Drift Mechanics**

  - Smooth, responsive drift controls
  - Drift boost system
  - Drift scoring/combo system

- **Combat Systems**

  - Player shooting (primary attack)
  - Bomb attacks (secondary attack)
  - Enemy variety (5-10 types minimum)
  - Clear hit feedback

- **Map Design**
  - 10-15 complete maps (floors)
  - Clear navigation
  - Environmental obstacles
  - Victory conditions for each map

### Progression

- **Basic Meta-Progression**

  - Unlock system (weapons/abilities)
  - Currency/points system
  - Run persistence (what carries over)

- **Session Progression**
  - Map-to-map advancement
  - Difficulty curve
  - Clear ending state

### Technical

- **Core Systems**

  - Save/load functionality
  - Settings menu (volume, controls)
  - Pause menu
  - Death/restart flow

- **Performance**
  - Stable 60 fps on target hardware
  - No major bugs
  - Clean build process

### Art & Audio

- **Programmer Art** (placeholder visuals)

  - Simple shapes/sprites
  - Clear readability
  - Functional UI

- **Temporary Audio**
  - Royalty-free music
  - Basic sound effects
  - Audio mixing

---

## ❌ What's NOT Included

### Deferred to Later Versions

- Custom pixel art (v0.2)
- Original music (v0.3)
- Boss fights (v0.4+)
- Multiple game modes (v0.4+)
- Advanced meta-progression (v0.4+)
- Achievements (v1.0)
- Leaderboards (v1.0)

### Intentional Cuts

- Tutorial system (add if time permits)
- Story/narrative elements
- Multiple characters/ships
- Multiplayer/co-op

## 🎮 Gameplay Flow (Planned)

1. **Main Menu**

   - Start Run
   - Settings
   - Quit

2. **Run Start**

   - Select loadout (if unlocks available)
   - Enter first map

3. **Map Gameplay**

   - Navigate level
   - Defeat enemies
   - Collect pickups
   - Reach goal

4. **Between Maps**

   - Score screen
   - Unlock notification
   - Continue or quit

5. **Run End**
   - Final score
   - Unlock progression
   - Return to menu

## 📝 Known Risks

**Scope Creep**

- Risk: Adding features beyond MVP
- Mitigation: Lock scope in November, no additions after

**Technical Debt**

- Risk: Rushing leads to unstable foundation
- Mitigation: Allocate extra time for refactoring

**Playtime Target**

- Risk: 30-45 min might be too short/long
- Mitigation: Playtesting in March, adjust content

**May 1 Deadline**

- Risk: Might slip schedule
- Mitigation: Cut "should have" features if needed

## 💬 Success Metrics

**For v0.1 to be successful:**

- At least 5 playtesters provide feedback
- Average playtime is 30-45 minutes
- Core gameplay loop is rated "fun" by majority
- No game-breaking bugs in first week
- Clear path forward for v0.2
