# Drift Tower - Roadmap

## 🎯 Vision

Solo indie game: drift-based combat with roguelike progression. Everything built from scratch - code, art, music.

**Core Loop:** Drift → Shoot → Bomb → Clear Maps → Progress

---

## 🚀 The Plan (Iterative Releases)

### v0.1.0 - "The Prototype" (May 1, 2026)

**Goal:** First complete 30-45 minute playable experience

**What's included:**

- 10 complete maps (floors)
- 2-3 enemy types
- Clear beginning, middle, end
- Basic progression system
- Programmer art (placeholder visuals)
- Temporary music/sound

**Why this matters:** Proves the core gameplay loop is fun

## 🎮 Design Pillars

1. **Drift-first combat** - Movement IS the combat system
2. **Quick sessions** - Clear a map in 5-10 minutes
3. **Meaningful progression** - Unlocks that change how you play
4. **Handcrafted levels** - No procedural generation (yet?)
5. **Controller-first** - Built for gamepad play

---

## 🔄 Development Philosophy

**Iterative & Public:**

- Ship every 6 months
- Document everything
- Share progress daily
- Learn in public

**Scope Management:**

- Finish systems before adding new ones
- No feature creep between versions
- Cut ruthlessly to hit deadlines

**Quality over Speed:**

- Polish core mechanics first
- It's okay to delay for quality
- Better late than broken
